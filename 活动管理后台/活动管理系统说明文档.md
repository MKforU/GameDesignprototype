# 活动管理系统 — 配置说明与数据口径文档

> 本文档用于策划/运营配置活动时的字段说明，以及数据统计页各指标的定义与计算口径。
> 最后更新：2026-08-27

---

## 一、活动列表配置

### 1.1 操作按钮

| 按钮 | 说明 |
|------|------|
| **编辑** | 进入活动编辑页，配置基本信息、任务、商城、里程碑 |
| **复制** | 一键复制整个活动（含所有任务、商城商品、里程碑），名称自动加「（副本）」后缀，状态默认未上线，所有子项默认下线。适合基于已有活动快速创建新活动 |
| **删除** | 删除活动及其所有子数据，不可恢复 |
| **🚀 推送** | 将活动配置推送到正式服 |

### 1.2 基本信息

| 字段 | 说明 | 示例 |
|------|------|------|
| **活动名称** | 活动的显示名称，必填 | 七夕限定·星光舞台 |
| **活动类型** | `限时活动`（有结束时间）/ `常规活动`（长期开放） | 限时活动 |
| **开启时间** | 活动生效的起始时间，必填 | 2026-08-25 10:00 |
| **结束时间** | 活动关闭时间，留空则永不结束 | 2026-09-01 23:59 |
| **周期刷新规则** | `不刷新` / `每日刷新` / `每周刷新` / `每月刷新` | 每日刷新 |
| **刷新时刻** | 配合刷新规则，任务/积分重置的时间点 | 05:00 |
| **活动描述** | 活动的文案说明，展示在活动详情页 | 完成任务收集星光… |
| **活动规则** | 点击「📖规则」按钮时展示的规则文案 | 1. 每日登录… |
| **上线状态** | `上线` = 玩家可见 / `下线` = 玩家不可见 | 上线 |

### 1.3 图片资源

| 字段 | 用途 | 建议 |
|------|------|------|
| **Banner图文件名** | 活动详情页内的顶部展示图 | 活动内通用预制体尺寸 |
| **活动中心入口图** | 活动中心列表中的封面缩略图 | 建议方形或接近方形 |
| **主界面轮播图** | 主界面轮播Banner位 | 与主界面轮播控件尺寸一致 |

### 1.4 白名单

| 字段 | 说明 |
|------|------|
| **白名单模式** | `全量用户` = 所有玩家可见 / `指定ID` = 仅白名单内玩家可见 |
| **白名单ID列表** | 每行一个玩家ID，仅在「指定ID」模式下生效 |

### 1.5 积分体系

本系统采用**双积分体系**，完成任务时**同时**发放两种积分：

| 积分类型 | 用途 | 来源 |
|---------|------|------|
| **商城积分** | 在积分商城中兑换商品 | 完成任务获得 |
| **里程碑积分** | 推动里程碑进度条，解锁里程碑奖励 | 完成任务获得（与商城积分1:1同步发放） |

> 两种积分独立核算但按 1:1 比例同步发放。任务配置中的「积分」字段为同时发放的数量。

## 二、任务管理

### 2.1 操作按钮

| 按钮 | 说明 |
|------|------|
| **🟢/⚫ 上线/下线** | 切换任务在客户端的可见状态 |
| **编辑** | 编辑任务的所有配置 |
| **复制** | 复制当前任务的所有配置（类型、目标、奖励等），名称加「（副本）」后缀，默认下线，追加到任务列表末尾 |
| **删除** | 删除该任务 |

### 2.2 任务类型与目标方式

| 任务类型 | 目标方式 | 说明 |
|---------|---------|------|
| **登录** | 任意登录 | 完成任意一次登录 |
| **签到** | 任意签到 | 完成任意一次签到 |
| **充值** | 累计充值次数 / 累计充值金额（元） | 达到指定次数或金额 |
| **送礼** | 任意礼物 / 指定礼物（累计满足） / 指定礼物（任意满足） / 指定礼物（全部完成） | 见下方详解 |
| **通关** | 任意玩法 / 指定玩法（累计满足） / 指定玩法（任意满足） / 指定玩法（全部完成） | 见下方详解 |
| **消耗物品** | 消耗指定物品（累计满足） / 消耗指定物品（任意满足） / 消耗指定物品（全部完成） | 见下方详解 |
| **在线时间** | 累计在线时长 | 活动期间累计在线达到指定时长（分钟） |
| **完成UGC购买** | 完成指定服饰UGC购买（累计满足/任意满足/全部完成） | 见下方详解 |
| **拥有指定道具** | 拥有指定道具（计算背包内所有） / 拥有指定道具（活动开启后新获得） | 统计背包中指定物品数量 |
| **自定义** | 任意触发 / 指定触发（任意满足） / 指定触发（全部完成） | 开发自定义判定逻辑 |

### 2.3 目标方式详解（累计满足 / 任意满足 / 全部完成）

以「送礼」为例，目标值 = 5，指定礼物ID列表 = [A, B, C]：

| 模式 | 计数方式 | 达标条件 | 举例 |
|------|---------|---------|------|
| **累计满足** (pool) | 所有指定物品**共享一个计数器** | 任意指定物品的赠送次数之和 ≥ 目标值 | 送A×2 + 送B×3 = 5 ✅ |
| **任意满足** (or) | **单个物品**独立计数 | 任意一个指定物品的赠送次数 ≥ 目标值 | A送了5次 ✅（B和C不管） |
| **全部完成** (and) | **每个物品**独立计数 | 每个指定物品的赠送次数都要 ≥ 目标值 | A×5 且 B×5 且 C×5 ✅ |

> 「拥有指定道具」的两种模式区别：
> - **计算背包内所有**：统计玩家背包中该物品的当前总量（含活动前已拥有的）
> - **活动开启后新获得**：仅统计活动开启时间之后新获得的数量

### 2.4 任务其他字段

| 字段 | 说明 |
|------|------|
| **目标值** | 完成任务需要达到的数值（不同目标方式下含义不同，参见上方详解） |
| **每周期最大完成次数** | 该任务在一个刷新周期内可完成的次数上限，0 = 不限 |
| **活动期最大完成次数** | 该任务在整个活动期间可完成的总次数上限，0 = 不限 |
| **周期刷新规则** | `不刷新` / `每日` / `每周` / `每月` |
| **获得积分** | 完成任务同时获得的商城积分和里程碑积分数量（1:1同步发放） |
| **发放方式** | `全部发放` = 所有奖励物品一起发 / `随机发放` = 从列表中随机抽取 / `自选发放` = 玩家自选一个 |
| **发放数量** | 仅在「随机发放」或「自选发放」时生效，表示随机/自选的物品个数 |
| **奖励物品列表** | 可添加多个物品，每个物品配置物品ID和数量 |
| **自定义代码** | 开发可编写特殊任务判定逻辑，留空则使用默认判定 |

## 三、积分商城

| 字段 | 说明 |
|------|------|
| **兑换奖励物品** | 商品包含的奖励物品列表，支持添加多个物品（物品ID + 数量） |
| **所需商城积分** | 兑换该商品消耗的商城积分 |
| **每人兑换上限** | 每个玩家可兑换的次数上限，0 = 不限 |
| **开启开始/结束时间** | 商品上架/下架时间，留空则跟随活动时间 |
| **上线状态** | 下线后玩家端无法看到此商品 |

---

## 四、里程碑奖励

| 字段 | 说明 |
|------|------|
| **里程碑维度** | `个人` = 单人累计积分 / `战队` = 战队成员累计总和 / `全服` = 全服玩家累计总和 |
| **所需里程碑积分** | 解锁该档里程碑需要的里程碑积分门槛 |
| **里程碑奖励物品** | 解锁后发放的奖励物品列表，支持添加多个物品（物品ID + 数量） |
| **开启开始/结束时间** | 里程碑生效时间，留空则跟随活动时间 |

> 里程碑进度由**里程碑积分**驱动（与商城积分1:1同步发放），里程碑奖励中**不含积分**，仅发放物品。

## 五、数据统计口径

### 5.1 概览指标

| 指标 | 口径 | 计算公式 |
|------|------|---------|
| **总参与人次** | 活动期间至少完成过1次任务的去重玩家数 | `COUNT(DISTINCT player_id) WHERE task_completed > 0` |
| **任务完成次数** | 所有任务被完成的总次数（同一任务重复完成计多次） | `SUM(task_completion_count)` |
| **任务完成率** | 任务完成总次数 ÷ 参与人次 | `任务完成次数 / 总参与人次 × 100%` |
| **充值总额** | 活动期间玩家的所有充值金额（口径C：只要活动内有充值任务，活动期间的全部充值都计入） | `SUM(recharge_amount) WHERE activity_has_recharge_task` |
| **充值人数** | 活动期间有充值行为的去重玩家数（同口径C） | `COUNT(DISTINCT player_id) WHERE recharged > 0 AND activity_has_recharge_task` |
| **积分发放总量** | 活动期间发放的商城积分总量（= 里程碑积分总量） | `SUM(shop_points_issued)` |
| **人均获得积分** | 积分发放总量 ÷ 参与人次 | `积分发放总量 / 总参与人次` |
| **积分兑换率** | 已消耗的商城积分 ÷ 发放的商城积分总量 | `积分兑换量 / 积分发放总量 × 100%` |
| **积分留存率** | 未消耗的商城积分占比 | `1 - 积分兑换率`（即 发放量-兑换量 / 发放量 × 100%） |
| **奖励领取率** | 已领取的任务奖励次数 ÷ 可领取的任务奖励总次数 | `已领取奖励次数 / (完成次数 × 奖励物品数) × 100%` |
| **里程碑解锁率** | 各档里程碑解锁总人数 ÷ (里程碑档位数 × 参与人次) | `SUM(各档解锁人数) / (档位数 × 总参与人次) × 100%` |

### 5.2 趋势图表

| 图表 | 数据口径 |
|------|---------|
| **参与人次趋势** | 按天统计当日新增参与人数（去重） |
| **积分发放趋势** | 按天统计当日发放的商城积分总量 |

### 5.3 排行榜

| 排行 | 排序规则 | 展示内容 |
|------|---------|---------|
| **任务完成排行** | 按完成次数降序，取Top 5 | 任务名称、所属活动、完成次数 |
| **商品兑换排行** | 按兑换次数降序，取Top 5 | 商品名称、所属活动、兑换次数 |

### 5.4 任务完成明细

| 字段 | 口径 |
|------|------|
| **完成次数** | 该任务被完成的总次数 |
| **完成率** | `该任务完成次数 / 活动参与人次 × 100%`（注意：同一玩家可完成多次，完成率可能>100%） |

### 5.5 里程碑解锁概览

按活动分组，逐档展示：

| 字段 | 口径 |
|------|------|
| **解锁人数** | 达到该档积分门槛的去重玩家数 |
| **解锁率** | `该档解锁人数 / 活动参与人次 × 100%` |

### 5.6 商城库存消耗

| 字段 | 口径 |
|------|------|
| **已兑换** | 该商品被兑换的总次数 |
| **剩余** | 商品配置总量 - 已兑换量 |
| **消耗进度条** | 颜色含义：<50% 绿色 / 50%-80% 黄色 / >80% 红色（预警） |

### 5.7 活动数据明细表

| 列 | 口径 |
|----|------|
| 活动名称 / 状态 | 基本信息 |
| 参与人次 | 同概览指标 |
| 任务完成 / 完成率 | 同概览指标 |
| 积分发放 / 人均积分 | 同概览指标 |
| 积分兑换 / 兑换率 | 同概览指标 |
| 积分留存 | 同概览指标 |
| 奖励领取率 | 同概览指标 |
| 充值总额 | 同概览指标 |
| 里程碑解锁 / 解锁率 | 同概览指标 |

## 六、注意事项

1. **统计范围**：所有指标均基于单个活动维度统计，筛选「全部活动」时为跨活动聚合
2. **时间筛选**：支持自定义日期区间（起止日期选择器），趋势图表按所选日期范围过滤
3. **积分双体系**：商城积分和里程碑积分按 1:1 同步发放，但消耗渠道独立
4. **里程碑维度**：个人/战队/全服三个维度独立统计，互不影响
5. **数据导出**：点击「📥 导出报表」可导出当前筛选条件下的数据（对接后端时实现）
6. **mock数据**：当前为前端模拟数据，对接后端后需替换 `mockStats` 和 `dailyTrend` 数据源
7. **复制功能**：活动复制会复制全部子数据（任务、商城、里程碑），所有副本默认未上线/下线状态，需手动上线
